AT&T Fiber Gateway Login (192.168.1.254)

Default login credentials, IP passthrough, bridge mode instructions, and factory reset procedure for AT&T Fiber BGW320 / BGW210 Gateway.

Verified ISP Configuration
Gateway IP: 192.168.1.254 • User: admin • Pass: Printed Device Access Code (DAC)
AT&T does not use a generic password. You MUST locate the 10-digit 'Device Access Code' printed in bold on the yellow/white sticker on the back or base of the BGW320.

How to Enable Bridge Mode or IP Passthrough

AT&T modems do not offer true bridge mode; use 'IP Passthrough': Navigate to http://192.168.1.254 > Firewall > IP Passthrough. Set Allocation Mode to 'Passthrough', Passthrough Mode to 'DHCPS-fixed', and select your router's MAC address from the Device List.

Physical Factory Reset Procedure

Press and hold the red Reset button on the rear for 20 seconds. The front status light will flash fast green, signaling a factory reset.
