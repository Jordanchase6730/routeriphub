Local Router Gateway Auto-Detector

Browser-based WebRTC and local probe utility that detects your active gateway subnet (192.168.1.1, 192.168.0.1, or 10.0.0.1).

Click the button below to allow the browser to analyze your active network interface and detect whether your default gateway is running on 192.168.1.1, 192.168.0.1, or 10.0.0.1.

How the Local Router Gateway Auto-Detector Works

Your default gateway is the primary local IP address of your router that acts as an access point or gateway between your local home network (LAN) and the wider Internet (WAN). When you click "Auto-Detect My Router IP", this tool executes a lightweight probe against common gateway subnets:

  • Local Subnet Probing: The browser tests fetch timing against standard private router IP ranges (192.168.1.1, 192.168.0.1, 10.0.0.1, 192.168.2.1, and 192.168.1.254).
  • WebRTC ICE Discovery: Utilizes browser WebRTC candidates to detect your computer's local IPv4 binding.
  • 100% Client-Side Privacy: All probes are handled locally by JavaScript; no internal network details are ever logged or transmitted externally.

Manual Command Line Discovery Methods

If browser auto-detection is blocked by browser security extensions or firewall rules, you can instantly find your gateway using your computer's built-in terminal:

  • Windows (CMD / PowerShell): Open terminal and run ipconfig | findstr /i "Default Gateway"
  • macOS (Terminal): Open terminal and run netstat -nr | grep default or route -n get default
  • Linux (Terminal): Run ip route show default
  • iPhone / iPad (iOS): Go to Settings > Wi-Fi > tap the blue (i) icon > look for Router.
  • Android: Go to Settings > Network & internet > Internet > tap your network > Gateway.
